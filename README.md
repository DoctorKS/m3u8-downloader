# M3U8 Video + Audio Downloader

GUI สำหรับจัดคิวดาวน์โหลดลิงก์ HLS `.m3u8` หลายรายการ โปรแกรมสามารถรวมเสียงกับวิดีโอ ดาวน์โหลดเฉพาะเสียง หรือดาวน์โหลดเฉพาะวิดีโอทีละรายการตามลำดับคิวโดยไม่ re-encode

## สิ่งที่ต้องมี

- Windows 10/11
- Python 3.10 หรือใหม่กว่า
- ffmpeg ใน PATH

ติดตั้ง ffmpeg ผ่าน PowerShell:

```powershell
winget install Gyan.FFmpeg
```

หลังติดตั้งให้ปิดและเปิด Terminal ใหม่ แล้วตรวจสอบด้วย:

```powershell
ffmpeg -version
```

## วิธีใช้งาน

เปิด `run.bat` หรือรันคำสั่ง:

```powershell
python app.py
```

1. กรอกลิงก์ `.m3u8` ในช่องเสียงและ/หรือวิดีโออย่างน้อย 1 ช่อง
   - กรอกทั้งสองช่อง: รวมเสียงกับวิดีโอเป็น `.mp4`
   - กรอกเฉพาะเสียง: ดาวน์โหลดเฉพาะ audio stream เป็น `.m4a`
   - กรอกเฉพาะวิดีโอ: ดาวน์โหลดเฉพาะ video stream เป็น `.mp4` โดยไม่รวมเสียง
2. เลือกตำแหน่งบันทึกไฟล์ `.mp4` หรือ `.m4a` ตามโหมด
3. กด **เพิ่มเข้าคิว** แล้วทำซ้ำสำหรับรายการอื่น
4. กด **เริ่มดาวน์โหลดตามคิว**

โปรแกรมจะประมวลผลทีละรายการ รายการที่เหลือจะแสดงสถานะ **รอคิว** และ progress bar จะแสดงเปอร์เซ็นต์ของรายการที่กำลังทำงาน

ลิงก์ตัวอย่างที่ให้มาถูกกรอกไว้เป็นค่าเริ่มต้นแล้ว

> ควรดาวน์โหลดเฉพาะเนื้อหาที่คุณมีสิทธิ์เข้าถึงและบันทึกเท่านั้น
