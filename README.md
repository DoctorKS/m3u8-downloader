# M3U8 Video + Audio Downloader

GUI อย่างง่ายสำหรับดาวน์โหลด HLS เสียงและวิดีโอจากลิงก์ `.m3u8` พร้อมกัน แล้วรวมเป็นไฟล์ MP4 โดยไม่ re-encode

## สิ่งที่ต้องมี

- Windows 10/11
- Python 3.10 หรือใหม่กว่า
- ffmpeg ใน PATH

ติดตั้ง ffmpeg ผ่าน PowerShell:

```powershell
winget install Gyan.FFmpeg
```

หลังติดตั้งให้ปิดและเปิด Terminal ใหม่ แล้วตรวจสอบด้วย:

```powershell
ffmpeg -version
```

## วิธีใช้งาน

เปิด `run.bat` หรือรันคำสั่ง:

```powershell
python app.py
```

1. กรอกลิงก์เสียงและวิดีโอ `.m3u8`
2. เลือกตำแหน่งบันทึกไฟล์ `.mp4`
3. กด **ดาวน์โหลดและรวมไฟล์**

ลิงก์ตัวอย่างที่ให้มาถูกกรอกไว้เป็นค่าเริ่มต้นแล้ว

> ควรดาวน์โหลดเฉพาะเนื้อหาที่คุณมีสิทธิ์เข้าถึงและบันทึกเท่านั้น
