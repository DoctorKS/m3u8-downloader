# M3U8 Video + Audio Downloader

GUI สำหรับจัดคิวดาวน์โหลด/แปลงวิดีโอหลายรายการ รองรับลิงก์ HLS `.m3u8`, ลิงก์วิดีโอ `.mp4`, และไฟล์ `.mp4` ในเครื่อง โปรแกรมจะรวมเสียง/วิดีโอหรือ remux เป็น MP4 ทีละรายการตามลำดับคิวโดยไม่ re-encode

## สิ่งที่ต้องมี

- Windows 10/11
- Python 3.10 หรือใหม่กว่า
- ffmpeg ใน PATH

ติดตั้ง ffmpeg ผ่าน PowerShell:

```powershell
winget install Gyan.FFmpeg
```

หลังติดตั้งให้ปิดและเปิด Terminal ใหม่ แล้วตรวจสอบด้วย:

```powershell
ffmpeg -version
```

## วิธีใช้งาน

เปิด `run.bat` หรือรันคำสั่ง:

```powershell
python app.py
```

1. กรอกแหล่งเสียง `.m3u8/.mp4` หรือเว้นว่างถ้าวิดีโอ `.mp4` มีเสียงอยู่แล้ว
2. กรอกลิงก์วิดีโอ `.m3u8/.mp4` หรือกด **เลือก MP4...** เพื่อเลือกไฟล์ในเครื่อง
3. เลือกตำแหน่งบันทึกไฟล์ `.mp4`
4. กด **เพิ่มเข้าคิว** แล้วทำซ้ำสำหรับวิดีโอรายการอื่น
5. กด **เริ่มดาวน์โหลดตามคิว**

โปรแกรมจะประมวลผลทีละรายการ รายการที่เหลือจะแสดงสถานะ **รอคิว** และ progress bar จะแสดงเปอร์เซ็นต์ของรายการที่กำลังทำงาน

ลิงก์ตัวอย่างที่ให้มาถูกกรอกไว้เป็นค่าเริ่มต้นแล้ว

> ควรดาวน์โหลดเฉพาะเนื้อหาที่คุณมีสิทธิ์เข้าถึงและบันทึกเท่านั้น
